# THIRANEX Data Analytics Internship

## About the Internship

This repository contains the practical work completed during my THIRANEX Data Analytics Internship.

The internship provided practical experience in data analysis, machine learning, data cleaning, visualization, and reporting using Python.

## Projects

### 1. Sales and Revenue Analysis

This project focuses on analysing sales, profit, category-wise performance, region-wise performance, and monthly sales trends using Python.

**Tools Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

### 2. Customer Segmentation using K-Means Clustering

This project demonstrates the K-Means clustering workflow using segment-level sales data.

The analysis uses total sales, total profit, and total quantity to demonstrate clustering.

**Tools Used:**
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

### 3. House Price Prediction using Linear Regression

This project demonstrates house price prediction using Linear Regression.

The model uses area, number of bedrooms, number of bathrooms, and age of the house as input features.

**Evaluation Metrics:**
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

**Note:** The dataset used for this project was synthetically generated for learning purposes.

---

### 4. Data Cleaning and Reporting Automation

This project demonstrates a Python-based data cleaning and reporting workflow.

The process includes:
- Data inspection
- Missing value checking
- Duplicate checking
- Data validation
- Data cleaning
- Summary report generation

**Tools Used:**
- Python
- Pandas
- NumPy
